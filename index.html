01 Profile

The developer behind the mochi.

A Python-first builder with a preference for small, readable systems.

Tam Kuan Hou — known online as Mochi-Sora and also as Marco Tam — has been building in public since July 2026.

His work is deliberately small in surface area: a standard-library agent core, explicit approval and evaluation layers, and tools that can be read, extended, and run locally. SoraAgent, the flagship, is licensed AGPL-3.0-only, so improvements to the harness stay in the open.

MasonAgent came first as its predecessor. The public work now spans the agent harness, Agensi skills, and the wider SoraPlatform roadmap.

03 SoraAgent

The engine, in detail.

A model-agnostic Python harness. The model/tool loop is deliberately small; approval, validation, evaluation, memory, and identity sit in explicit layers around it.

Human approval gate

Tools marked needs_approval never execute without a human saying yes.

Quality gate

Every finished trajectory is graded by a deterministic structural evaluator. The grade is advisory and cannot affect execution.

Lazy tool discovery

Only find_tools and memory_recall are visible at the start; the rest load on demand, keeping prompts small and tool lists bounded.

Local memory & identity

File-backed USER.md and SOUL.md, plus optional CortexDB recall with a memory firewall.

curl -fsSL https://raw.githubusercontent.com/Mochi-Sora/SoraAgent/main/install.sh | bash

Installs SoraAgent into an isolated virtual environment and adds the sora commands to your PATH.

irm https://raw.githubusercontent.com/Mochi-Sora/SoraAgent/main/install.ps1 | iex

Installs SoraAgent into an isolated environment on Windows and verifies the console scripts.

git clone https://github.com/Mochi-Sora/SoraAgent.git
cd SoraAgent
python -m venv .venv
source .venv/bin/activate
pip install -e ".[openai,memory,cli,files,dev]"

For contributors. On Windows, activate with .venv\Scripts\activate.
